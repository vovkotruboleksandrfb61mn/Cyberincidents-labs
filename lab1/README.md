## Завдання

Використовуючи модель логістичної регресії, виконати класифікацію програмного
забезпечення на шкідливе та безпечне.

## Датасет

[UCI Malware Executable Detection](https://www.kaggle.com/datasets/piyushrumao/malware-executable-detection) —
373 виконуваних файли Windows, 531 бінарна ознака (шістнадцяткові послідовності
байтів + виклики DLL), 301 шкідливий і 72 безпечних.

## Результати

| Модель | Точність | Recall (безпечні) | F1 |
|--------|----------|-------------------|-----|
| Базова лінія («завжди шкідливий») | 0.809 | 0.000 | 0.894 |
| Логістична регресія (L2) | 1.000 | 1.000 | 1.000 |
| L1-відбір (3 ознаки) | 1.000 | 1.000 | 1.000 |

## Основні висновки

- **100 % точності тут нічого не означає.** Одна ознака `F_19` збігається з
  міткою у 98.4 % випадків, дві ознаки дають F1 = 0.9983 — краще, ніж усі 503.
  Ознаки конструювали саме для відокремлення шкідливих файлів, тож лінійна
  роздільність закладена в них за побудовою.
- **Датасет непридатний для порівняння алгоритмів.** Розкид результатів між
  методами — 0.005; будь-який метод дає ~99 %. Для наступних робіт потрібні
  складніші дані.
- **Точність як метрика оманлива за дисбалансу.** Тривіальний класифікатор дає
  80.9 %, не розпізнавши жодного безпечного файлу.
- **Пастка у відборі ознак.** `SelectFromModel(threshold="median")` не відбирає
  нічого, якщо L1 занулила більше половини коефіцієнтів: медіана важливості
  дорівнює нулю, і умова «важливість ≥ медіани» виконується для всіх ознак.
