## Завдання

Реалізувати метод опорних векторів, оцінити точність та фактори, від яких вона
залежить.

## Датасет

[UGRansome](https://www.kaggle.com/datasets/nkongolo/ugransome-dataset) — той
самий, що в роботі № 2, щоб результат SVM порівнювався з деревом, лісом і
логістичною регресією напряму. Через складність методу аналіз виконано на
стратифікованій підвибірці 30 000 записів зі 149 043.

## Результати

| Модель | Точність (CV) |
|--------|---------------|
| Випадковий ліс | 0.9910 |
| Дерево рішень | 0.9907 |
| **SVM (RBF, C = 100, γ = 0.1)** | **0.9727** |
| SVM (лінійне ядро) | 0.7606 |
| Логістична регресія | 0.7480 |

## Основні висновки

- **Фактори за величиною впливу.** Масштабування ознак — **+32 пункти**
  (0.6354 → 0.9552); вибір ядра — +20 (лінійне → RBF); підбір `C` і `gamma` —
  +1.2; збільшення вибірки вдвічі — +0.9. Найбільший виграш дає найпростіша дія.
- **Чому масштабування вирішальне.** Ознака `USD` має розмах 126 378 проти 8 у
  `Flag`; без стандартизації евклідова відстань визначається майже виключно нею.
  Для дерев масштаб натомість байдужий.
- **SVM погано масштабується.** Емпірична складність ≈ O(n^1.6): дані зросли у
  40 разів, час навчання — приблизно у 350. На 40 000 прикладів точність ще
  зростає, але використати всі 149 043 записи, доступні деревам, неможливо.
- **На цих даних SVM програє деревам** (0.9727 проти 0.9907): ознаки переважно
  категоріальні, а кодування категорій цілими числами нав'язує їм неіснуючий
  порядок, з яким гладка ядрова межа працює гірше за дискретні розбиття.
- Для лінійного випадку слід брати `LinearSVC`, а не `SVC(kernel="linear")` —
  та сама точність за час, менший на два порядки.
